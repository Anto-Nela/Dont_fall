# Dont_fall
My amazing naming skills strike again xD. This is a game made for and by following the Unity Junior Pathway.
The goal is for the player (a sphere) avoid falling off a platform whilst being followed by enemies (evil spheres) and simultaneously trying to kick the enemies off said platform. 

The main game can be found under Assets > Scenes > Prototype 4.

Made in a 3D environment with unity version 6000.3.8f1.
